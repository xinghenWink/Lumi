# 无限画布工作台

在「无限画布」新建项目。拖动空白处平移，滚轮缩放，Ctrl／Cmd 加拖动框选。双击空白处或用「添加节点」打开创建菜单。拖动图片、文本或分组的连接点，可以连接节点或在空白处新建节点并连线。

空图片可以上传，也可以在原位生成。选中已有图片可新建生成节点，继续用它作参考。运行前确认参数、输入和积分报价。刷新会继续跟踪服务端已接受的生成任务。

## 升级

1. 停掉连接目标数据库的旧版 Lumi 实例和 worker。要保留升级前的旧画布，请在运行迁移前备份数据库和媒体目录。
2. 使用同一新版镜像运行 `lumi migrate`，或按当前部署流程由新版 `lumi serve` 应用迁移 00011。迁移会删除所有旧画布及文件引用，关闭关联会话，并将旧画布产出的图片移出图库。已有积分记录保留，未完成任务由新版 worker 取消和退款。普通生图项目和其作品继续可用。
3. 启动新版实例，检查就绪接口。登录确认旧画布链接返回 404，并创建一张新画布，运行一次生图后刷新确认恢复。恢复旧画布需要同时恢复升级前的数据库和媒体备份。
