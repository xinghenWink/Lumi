# 无限画布工作台

在「无限画布」新建项目。拖动空白处平移，滚轮缩放，Ctrl／Cmd 加拖动框选。双击空白处或用「添加节点」打开创建菜单。拖动图片、文本或分组的连接点，可以连接节点或在空白处新建节点并连线。

选中图片、文本或生成节点，使用节点上方的操作条和下方的编辑器。小屏通过操作条打开底部面板。双击文本可编辑正文。编辑器的「＋」会把选中的画布素材连入当前节点。输入 `@` 可在已连接的素材中搜索，使用方向键和 Enter 选取。断开连线后，删除失效标记或重新连线即可提交。

空图片接收首张结果。已有图片会作为参考并保留，结果放在右侧。生成前确认模型、参数和积分报价。裁剪、切分和插值放大的结果在上传齐全后一次加入画布，可以一次撤销。

文本节点支持聊天模型和 1–3 条候选。推理选项由管理员按模型启用，图片引用需要视觉模型。空文本接收首条候选，改写结果在原稿右侧。每条候选使用一条聊天额度。两类任务均可在刷新后继续跟踪。

## 从 00011 升级到 00012

使用新版 `lumi migrate`，或由新版 `lumi serve` 应用迁移。00012 只创建文本运行和候选记录，保留现有画布、文件、任务和积分记录。使用原实例的数据库、媒体目录和部署密钥，检查就绪接口后打开一张现有画布，并提交一条文本候选验证刷新恢复。

## 从 00010 或更早版本升级

1. 停掉连接目标数据库的旧版 Lumi 实例和 worker。要保留升级前的旧画布，请在运行迁移前备份数据库和媒体目录。
2. 使用同一新版镜像运行 `lumi migrate`，或按当前部署流程由新版 `lumi serve` 应用迁移 00011。迁移会删除所有旧画布及文件引用，关闭关联会话，并将旧画布产出的图片移出图库。已有积分记录保留，未完成任务由新版 worker 取消和退款。普通生图项目和其作品继续可用。
3. 启动新版实例，检查就绪接口。登录确认旧画布链接返回 404，并创建一张新画布，运行一次生图后刷新确认恢复。恢复旧画布需要同时恢复升级前的数据库和媒体备份。

## 生图比例与分辨率

生图页和画布使用同一套系统预设。选择比例后，可直接选择 1K、2K 或 4K，并看到实际发送的像素尺寸。切换比例时，若新比例支持原分辨率，会沿用该档。后台「生图设置」可分别启停比例和分辨率，各保留至少一项。

迁移 00013 启用预设并保留现有尺寸、比例映射和任务。后台新建图片模型默认使用系统尺寸预设。已有模型仍以已配置的支持尺寸为准。确认上游支持系统预设后，可在「平台模型」打开「使用系统尺寸预设」。图片模型可勾选支持的 1K、2K、4K 档位，生图和画布按模型显示可用尺寸。手动新建图片模型默认勾选 1K。

- [x] Chrome 桌面和 320／390 px 覆盖比例、分辨率、后台开关和画布参数弹窗。桌面另验证任务记录中的 3:2、2K 像素尺寸。
- [x] 真实 PostgreSQL／Redis 验证从 00012 升级、自定义配置保留、开关保存及重开、并发版本冲突。试用实例已应用 00013。
