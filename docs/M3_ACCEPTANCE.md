## 已确认的阶段边界

本阶段只执行用户授权的一次生图和一次改图，不对上游发压测或批量图片请求。vision、system 语义遵循、其他质量 / 尺寸 / 张数上限、JSON / 多参考图编辑和实际 429 错误体仍未验证；不据模型名推断能力。导入默认关闭未确认的 vision / 编辑，运营者须依据契约配置后启用。

M4 接入实际会话 / 消息、SSE 输出及 Markdown；M5 接入文件存储、图像任务、扣费退款与恢复。实际图片尺寸须从文件读取。健康熔断、按优先级 / 权重故障切换和环境首次自动引导属于 P1，尚未宣称交付。
