# M2 积分与兑换码

基线：M0 / M1 已合并至 main（`8fdd609`），主分支 CI 与双架构发布均成功。用户授权进入 M2，使用分支 `codex/m2-credits-redemption`，独立 PR 承载，不扩展 M3～M5 的模型与生成业务。

## 交付与一致性

- 新增 forward-only 积分账户、只增不改流水、幂等操作、扣费结算、价格规则、兑换批次/码/记录迁移，既有账号建立零永久余额账户，不追溯注册赠送。
- 所有积分变化经 `credits.Service`，事务锁账户、检查余额与整数边界、更新余额并追加流水。注册赠送/管理员初始积分与账号创建同事务。
- 按配置时区懒重置每日桶，旧余额过期、新赠送分别记账；先扣每日桶，再扣永久桶。任务费用快照，部分失败按原桶退款，跨日每日部分退入永久桶。
- 幂等键绑定操作者、业务与请求内容；相同请求返回原结果，键复用到不同请求返回冲突。管理员调整、兑换与批次生成也使用幂等键，审计与业务同事务。
- 兑换码使用密码学随机数生成 80 bit Crockford Base32；散列检索、加密保存供管理员导出。码行锁和唯一兑换记录保证并发次数及每人限兑一次；Redis 每分钟 5 次、连续失败 10 次冷却 1 小时。
- 积分流水与兑换历史保留稳定用户 UUID，不因账号保留期清理而删除或重写；不保留复制的邮箱/昵称。账户随账号清理，管理员审计保留。
- 价格使用整数积分，倍率使用有界精确十进制计算，按 `ceil(单价 × 编辑倍率 × 尺寸倍率) × 张数` 计费；支持全局与模型 ID 覆盖，禁用覆盖不回退绕过。

## 页面与状态

沿用原型与 M1 的靛紫强调色、现有字体/圆角/深浅色和独立后台。个人积分页用每日/永久分桶余额与重置时间构成主视图；30 天用量采用可访问柱状图，不引入图表依赖。

| 页面 | 实际交付状态 |
| --- | --- |
| 个人积分 | 加载/失败重试、双桶概览、兑换提交/幂等重试、明确码错误、流水类型/日期筛选及分页、兑换记录、30 天统计与真实空状态 |
| 用户列表与详情 | 真实余额列/筛选/排序、初始积分、积分与兑换记录 Tab、调整增加/扣减/设为、桶选择、必填备注、实时结果 |
| 后台价格与赠送 | 全局与模型覆盖、质量/操作开关、单价、精确倍率、注册/每日数量及时区校验、保存与错误反馈 |
| 后台兑换码 | 批量生成、批次/状态/搜索及分页、启用/禁用/未使用删除、复制、筛选导出、兑换记录及用户/码筛选 |
| 后台积分流水 | 用户/类型/日期筛选、分页、CSV 导出、防 CSV 公式注入 |

## 验证

Go 单元测试与真实 PG/Redis 集成覆盖并发不超扣、跨日/时区/夏令时、零赠送、交易与审计回滚、部分失败和跨日退款、价格快照、幂等冲突、兑换并发/多人码/错误与冷却、历史不可改和账号清理。前端覆盖运行时契约与文案编译、桌面与 320px 的真实注册→积分→兑换→后台调整/价格/导出流程。同步 OpenAPI、生成类型、运行说明与验收清单。

统计只读取已落库的真实扣费/结算记录。M2 没有生成任务时，生图统计为真实的零，不生成演示记录；聊天、模型、图片上传与任务调度按后续里程碑实现。
