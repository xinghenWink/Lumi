## 一致性和验证

- 新增 forward-only 迁移，不改写 M0～M2 迁移；配置变更、默认模型互斥和脱敏审计同事务，管理操作重查权限。
- API Key 使用既有 AES-GCM，绑定渠道 UUID；读取 API、审计、异常及探测报告不包含密钥。普通用户目录不暴露渠道、URL、真实模型名或路由。
- 上游 HTTP 只接受 http / https、无 URL 内嵌凭据 / 查询参数 / 片段，拒绝重定向；默认阻止私有 / 回环 / 链路本地地址，自托管内网需显式配置许可。
- 精确实例契约以探测报告为准。图像和改图探测为显式选项，记录实际参数及结果形状，不根据模型名猜测能力。
- 测试覆盖 CRUD / RBAC / 审计回滚 / 默认互斥 / 公开字段隔离，以及 httptest 的成功、超时、401、429、5xx、部分图片结果和 SSE 中断。
- 同步 OpenAPI / sqlc / 前端类型 / 文档，执行 Go 与前端质量检查、真实 PG / Redis 集成、桌面 / 320px 浏览器及生产 Compose。
