# M5 生图开发

基线：M4 `032285b` 的完整 CI 39781757856 全绿。独立分支 `codex/m5-images` 基于 M4，不自动合并前序 PR，不发布版本。

范围：F-IMG P0、F-ME-06、F-ADM-15，文件鉴权、WebP 缩略图与图像相关性能要求。页面包括生图会话 / 参数与费用、参考图选择、预览、个人图库、后台任务与图像配置；验收排队 / 运行 / 成功 / 部分成功 / 失败 / 取消，扣费退款、重启恢复、用户隔离和 320px 浅深色。

1. 新增 00007：文件、图像任务 / 图片项、图像配置；保留现有 conversations.type=image 和消息表。积分 ChargeTx / SettleTx 接入调用方事务，提交与扣费、结束与退款各自原子化。任务参数、单价和请求摘要快照，重试不重复扣费。
2. PostgreSQL 为任务事实源，Redis 有序队列用于调度；丢失入队由数据库扫描补偿。跨实例以数据库锁和租约执行用户 / 全站并发限制；只处理过期任务，不误伤健康实例。取消 / 超时 / 恢复全退，部分成功按快照单价退款。图像写请求不自动换路由重试，避免重复生成。
3. 文件校验魔数 / 解码头、大小与像素上限，PNG 重编码去除 EXIF，WebP 长边 ≤512。随机路径经 os.Root 约束；签名和登录同时校验，前端授权 fetch 转 Blob。缩略图用于列表，原图仅预览 / 下载。软删除、保留策略、未引用上传与磁盘清理有可重入维护。
4. 生图使用单独的 image-conversations API，复用类型为 image 的会话 / 消息表，保持现有聊天契约稳定。任务事件使用 SSE，断线降级 3 秒轮询，离开页面任务继续。分模式记录会话 / 模型 / 草稿，比例映射与实际尺寸分别记录。
5. 沿用 M3 已观察契约，不依据模型名开放能力，不额外调用真实收费生图。单元、真实 PG / Redis、HTTP 上游 fixture、桌面 / 320px、Compose 验证正常 / 部分 / 拒绝 / 超时 / 取消 / 重启 / 重复 / 并发与文件访问边界。

界面沿用 Lumi 靛紫 `#5856d6`、浅底 `#f7f8fc`、面板 `#ffffff`、正文 `#242637` 与现有深色变量；Segoe UI / PingFang SC 正文，等宽参数。保留开放消息流和底部输入区，模型在发送左侧向上展开；图片按稳定比例逐项展示状态，不用装饰性假进度。

依赖：nativewebp 1.3.0 以纯 Go 编码 WebP，适用于 CGO_ENABLED=0 / amd64 / arm64；golang.org/x/image 0.47.0 解码 WebP 与缩放。版本锁定并记录 DECISIONS。依据：[nativewebp](https://github.com/HugoSmits86/nativewebp)、[Go image](https://pkg.go.dev/golang.org/x/image)。

P1 边界：批量 zip / 删除、手动退款、加权随机 / 熔断、敏感词、聊天 vision 与完整运维页；M5 不顺带开发 M6。
