## 已运行检查

- `make lint test` 已在本机 GNU Make 下执行并通过，Go 使用发布工具链 1.26.10；Go lint 0 issues，前端 45 项 Vitest 通过，strict 类型与格式通过。
- `go test -tags=integration -count=1 ./...` 使用真实 Docker PG16 / Redis7 通过，包含 20 个阻塞续传读者不饿死普通 Redis 命令的新增回归。
- Playwright 桌面 + 320px 移动共 16 项通过；包括同一用户完整链路、500 消息、1000 个真实文件 / 缩略图、控制台错误观察与缩略图访问检查。
- 发布工具链 `GOTOOLCHAIN=go1.26.10` + govulncheck 1.9.0：0 个可调用 / 已导入包漏洞；另 1 个仅间接声明且未导入模块漏洞，退出 0。生产 npm audit：无已知漏洞。
- OpenAPI / sqlc 生成无代码差异；M7 无 SQL 迁移，不改 00001～00008，无运行时新依赖，quic-go 修复补丁已锁定。

所有性能报告为本地或 CI 实验室结果，图像由可控上游提供；没有把 fixture 或空目录 Compose 写成付费真实上游 / 干净远程服务器验收。失败轮次保留在忽略的 `.tools/`，最终 CI 证据将在本记录补齐。
