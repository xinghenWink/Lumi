# M4 真实聊天

M3 最终提交 `a4318df` 的完整 CI 39753475431 已通过。M4 使用独立分支 `codex/m4-chat`，PR 暂以尚未合并的 M3 为基础，不自动合并 M2 / M3。

范围：F-CHAT-01～07、F-ME-05 和聊天相关 NFR-P01～09。新增会话 / 消息 / 每日计数迁移，所有查询按当前用户隔离；持久化生成占用、2 秒检查点与租约恢复，SSE meta / delta / done / error，停止、中断保留、仅首段文本前的路由回退。管理员配置上下文、全局 system prompt、标题模型和独立聊天限额；聊天不消耗图像积分。

页面沿用靛紫 #5856d6、浅底 #f7f8fc、面板 #ffffff、正文 #242637 和现有深色变量；Segoe UI / PingFang SC 正文，等宽代码。特征是安静的开放式消息流和固定底部输入区，平台模型菜单位于发送按钮左侧并向上展开。侧栏显示真实会话，个人历史支持搜索、批量删除和清空；保留聊天 / 生图各自的路由、模型和内存草稿。320px 抽屉与桌面、浅深色均验收。

Markdown 默认禁用原始 HTML，并通过 DOMPurify 清洗最终 HTML；代码高亮和数学公式按需加载。流增量按 animation frame 合并，缓存已完成的 Markdown 块；输入组件与消息列表隔离，超过 100 条启用虚拟列表，滚动跟随用 IntersectionObserver 判断。

上下文保留 system，按模型能力与后台上限取较小 token 预算，最近 N 条裁掉最早完整轮次；超大单条拒绝而不静默裁剪。每日计数统一 UTC，已接收的发送 / 重生成 / 编辑各计一次，重复请求 UUID 不重复执行。路由回退按优先级稳定排序；权重随机、熔断、Redis 续传缓冲、vision 和个人自定义指令保留 P1。

验证包括上下文 / SSE / Markdown XSS / 限额、真实 PG / Redis 的幂等并发 / 隔离 / 中断 / 回退 / 恢复、桌面 / 320px 浏览器全流程、生成契约与生产 Compose。首次指标验收记录实际测量，不用模拟值声明性能达标。
