- 生成一致性：sqlc v1.31.1 与 `pnpm api:generate` 重新生成后无差异；OpenAPI 0.7.0。
- 前端：`pnpm lint`、`pnpm typecheck`、Prettier、`pnpm build` 通过；Vitest 36 个文件 152 项通过（新增 document / geometry / commands / history / workflow / tasks / clipboard、autosave / generation 控制器、拖放坐标与画布语言包一致性）。
- Playwright：本机全新 PG16 / Redis7 测试库，Chrome 桌面 + 320 + 390 全量 **60 项通过、3 项按设计跳过**（画布完整旅程只在桌面运行，移动检查只在两种移动宽度运行），用时 10.8 分钟。画布入口 `tests/canvas.spec.ts` 的 3 项（桌面完整旅程、320、390）均通过。既有生图、聊天、积分、后台与访客旅程无回归；SSE p95 桌面 / 320 / 390 为 31 / 26 / 25 ms，浏览器长任务 0。

## 已知限制

- 生成使用可控 HTTP 上游，不代表真实供应商的参数遵守；真实上游契约沿用 [UPSTREAM_CONTRACT](UPSTREAM_CONTRACT.md)。
- 从图库插入、拖动缩放柄、双指捏合缩放没有单独的浏览器自动化，由单测与类型检查覆盖。
- 首屏预算余量约 3.2 KB；后续壳层新增内容需要继续懒加载。
